# Proyecto java practica
Este repositorio contiene tres programas simples escritos en java como parte de una practica de Entornos de Desarrollo.
## Archivos incluidos
- `CarreraFuturista.java`: imprime información sobre una carrera futurista.
- `SaludGuerrero.java`: muestra datos relacionados con un personaje de salud.
- `tarjetaArtista.java`: genera una tarjeta con datos de una artista.
- ## Conceptos aprendidos
-  **Repositorio:** espacio donde se guarda y organiza el proyecto.
- **Commit:** guardar cambios con un mensaje descriptivo.
- **Push:** subir los cambios al repositorio en GitHub.
- **GitHub Desktop:** herramienta gráfica para trabajar con GitHub sin usar comandos.
